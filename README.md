# intervencija.eu

Source for [intervencija.eu](https://intervencija.eu/), the website of Intervencija, a senior-led software architecture and engineering consultancy.

Static HTML and CSS with no client-side framework and no third-party requests until a visitor submits the enquiry form. GitHub Actions builds, verifies and deploys the site to GitHub Pages on every push to `main`.

## Develop

```sh
npm ci
npm run serve:local   # http://127.0.0.1:8765
npm run ci:pages      # build, verify the source, run tests, verify the deployment artifact
```

## Layout

| Path | Contents |
|---|---|
| `index.html`, `system-audits/`, `critical-builds/`, `fractional-architecture/` | Commercial pages with enquiry forms |
| `insights/` | Articles and the insights index |
| `assets/theme.css` | Design system and page components |
| `assets/site.css` | Compiled Tailwind base, generated by `npm run build:css` |
| `assets/site.js` | Navigation, measurement events and the enquiry form |
| `assets/fonts/` | Self-hosted Inter and Playfair Display, see `assets/fonts/LICENSE.md` |
| `assets/og/`, `og-image.png` | Social preview images, rendered by `scripts/render-og.mjs` |
| `scripts/` | Build, verification, tests and social-card rendering |

Adding a page means adding it to `scripts/build-site.mjs`, `scripts/verify-dist.mjs`, `scripts/verify-site.mjs` and `sitemap.xml`. The verifier fails on a missing canonical, duplicate title, broken internal link, missing social image or third-party font request.

See [DEPLOYMENT.md](DEPLOYMENT.md), [MEASUREMENT.md](MEASUREMENT.md) and [BRAND_ASSETS.md](BRAND_ASSETS.md).
