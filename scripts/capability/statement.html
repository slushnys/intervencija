Capability statementNovember 2026

You set the objective. We deliver it, and sign for it.

Intervencija delivers software objectives for a fixed monthly fee. Our AI agent teams do the engineering, and a senior architect reviews every release, signs it and answers for it. Clients set the objectives and the budget, and we ask them only for the decisions that are theirs: scope, budget or deadline changes, risks to accept, and release go-aheads when they want them.

Engagements

Modernisation

Move a legacy system or module to a modern platform, with the old path kept as a fallback until the new one is proven.

  • A migration plan with milestones and success measures
  • Signed releases with test evidence
  • The old path retired once the new one is proven

Format: fixed monthly fee, agreed in a written proposal.

Product delivery

Deliver the objectives on a product roadmap, one signed release at a time.

  • Acceptance criteria agreed before work starts
  • Working features in your systems
  • A monthly report on progress, cost and risk

Format: fixed monthly fee, agreed in a written proposal.

Run and maintain

Keep software, integrations and dependencies working and up to date. For organisations without a software team, we host, run and fix it.

  • Security fixes and upgrades
  • Monitoring, with response times agreed in the proposal
  • Hosting and backups, if needed

Format: fixed monthly fee, agreed in a written proposal.

Every release is signed by a named senior architect: acceptance criteria met, automated tests passed with evidence, security checks passed, rollback plan checked, decision recorded. A first objective can run as a fixed-fee pilot. A System Audit, a fixed-fee review that ends with a plan and a price, is available when the starting point is unclear.

How we engage

Contracting
Master services agreement with a statement of work per engagement, on our paper or yours. An NDA can be signed before anything sensitive is shared.
Reporting
Monthly report on progress, cost and risk, a decision log, and a named architect for escalation.
Security
Each client’s work runs in a separate environment with its own credentials. Access agreed per scope and returned at the end. Security questionnaires are part of onboarding.
Data and AI
EU company working under the GDPR. A data processing agreement can be put in place, and we tell you which work our agents do.
Ownership
Code, tests and documentation delivered into your repositories, with ownership assigned to you.
Commercials
Fixed monthly fee per engagement, or a fixed fee for a pilot. Scope changes agreed in writing.
